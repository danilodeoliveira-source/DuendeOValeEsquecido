# DUENDE EXPLORADOR V17

Novidades:
- Mapa rápido com viagem entre as 3 regiões.
- Teleporte direto para Floresta, Pântano e Ruínas.
- Sistema de desafios diários.
- Recompensa diária de 100 moedas + 50 XP ao completar o desafio.
- Novo ARSENAL V17.
- Aprimoramento separado de arma e armadura.
- Nova relíquia: Amuleto do Vale.
- Estatísticas de viagens e desafios.
- Atalhos: Y = Viagem, Z = Arsenal, F9 = salvar.

Mantidos os sistemas anteriores: stop-motion real do duende, 3 regiões,
portais, santuários/checkpoints, chefe em 2 fases, clima, projéteis,
mapa, mochila, baús, moedas, poções, corrida, stamina, nível, XP,
equipamentos, loja, diário, missões, conquistas, mini-chefes, espólios,
arena de ondas e árvore de habilidades.

## V18
- Sistema de dificuldade: Fácil, Normal e Difícil.
- Modificadores preparados para velocidade, dano e chance de elite.
- Inimigos Elite com mais vida e recompensa.

- HUD V18.
- Tecla D = painel de Caçada.

## V19
- Oficina do Vale / sistema de crafting.

- Materiais: folhas, raízes, cristais e essências.
- Poção Grande, Elixir e Amuleto do Vale.
- Poção Grande adiciona uma poção ao inventário.
- Elixir e Amuleto têm efeitos preparados para o jogo.
- HUD de materiais.
- Tecla C = abrir Craft.
- Tecla X = ativar item especial disponível.
